# Product images

Put one image per product in this folder, named exactly as below.
The store shows the photo automatically; until then it shows a styled tile.

- Format: `.jpg`, `.png` or `.webp`
- Shape: portrait, 3:4 (for example 900 × 1200 px)
- Size: keep each file under about 300 KB so the page loads fast
- Use only images you created (e.g. AI-generated) or that are free to use.
  No brand logos, no real people's faces, no copied store photos.

Prompt template for an AI image tool (keeps the set consistent):

> Studio product photo of a [COLOR] [PRODUCT NAME], [short description],
> laid flat or on an invisible mannequin, plain warm off-white background,
> soft even lighting, minimalist fashion e-commerce style, portrait 3:4,
> no text, no logos, no people.
