# Synthetic Shop Data: Assumptions

Cartiva is fictional, so its shop data is generated by
[`analytics/generate_data.py`](../analytics/generate_data.py). Every number
below is a **choice**, set as a named constant at the top of that script.
Change a value, re-run the generator, and the dataset changes.

> **Honesty note:** any pattern in this data exists because an assumption
> below put it there. Analysis of this data demonstrates metric design and
> method. It does not describe real customer behavior.

The same seed (`2025` by default) always produces exactly the same data.

## Scope

| Assumption | Value | Why |
|---|---|---|
| Period | 2024-01-01 to 2025-12-31 | Two years allow year-over-year comparisons and two holiday seasons |
| Customers | 8,000 | Large enough for stable rates, small enough for Tableau Public |
| Store launch | January 2024 | The customer base starts at zero, so 2024 shows a growing new store |
| Catalog | 36 products, 87 variants, 9 categories | Shared with the app via `cartiva/catalog_data.py` |
| Customer location | 15 US states, weighted toward large states | US shipping only (CART-007) |

## Traffic

| Assumption | Value |
|---|---|
| Monthly traffic weights | Jan 0.80, Feb 0.75, Mar 0.85, Apr 0.90, May 0.95, Jun 1.00, Jul 1.05, Aug 1.00, Sep 0.95, Oct 1.00, **Nov 1.35, Dec 1.60** |
| Sale-day traffic | 2.5× a normal day |
| Return visits | After each visit, a 70% chance of another visit within the next 90 days |
| Visits after 2025-12-31 | Dropped (they fall outside the data period) |
| Device | Mobile 60%, desktop 35%, tablet 5% |
| First-visit channel | Organic search 35%, paid social 25%, direct 15%, email 15%, referral 10% |
| Return-visit channel | Email 35%, direct 35%, organic search 20%, paid social 10% |
| Time of day | Busier evenings, peaking around 8 pm |

## Shopping behavior

| Step | Base probability | Adjustments |
|---|---|---|
| Products viewed per session | 1–6 (2 most common) | Category popularity: Tops 1.4, Shirts 1.2, Jeans 1.2, Accessories 1.1, Dresses 1.0, Shoes 1.0, Skirts 0.9, Knitwear 0.8, Outerwear 0.7 |
| Add to cart, per product viewed | 12% | ×1.30 on sale days. Sold-out variants are never added. |
| Quantity | 1 (88%) or 2 (12%) | |
| Start checkout, if the cart is not empty | 55% | |
| Complete purchase, after starting checkout | 65% | See below |

Purchase adjustments (multiplied together):
- **Big-ticket hesitation**, based on the priciest item's category: Outerwear ×0.80, Shoes ×0.90, Accessories ×1.10
- **Device:** mobile ×0.85, desktop ×1.10, tablet ×1.00
- **Sale day:** ×1.15
- **WELCOME10 treatment group, before their first order (not on sale days):** ×1.15

## Promotions

Rules follow CART-004 to CART-006 in the requirements, implemented in
[`analytics/pricing.py`](../analytics/pricing.py) and tested against the
acceptance examples.

| Code | Type | Rule | Dates |
|---|---|---|---|
| WELCOME10 | Code | 10% off, minimum $50.00, max $20.00 off, first order only | Whole period |
| SUMMER2024 / SUMMER2025 | Automatic, sitewide | 15% off | Jul 8–14 2024 / Jul 7–13 2025 |
| BLACKFRIDAY2024 / BLACKFRIDAY2025 | Automatic, sitewide | 25% off | Nov 29–Dec 2 2024 / Nov 28–Dec 1 2025 |

- **One discount per order.** On sale days the sale applies and WELCOME10 is not accepted.
- **Shipping:** $5.99, free only when the total after discounts is above $100.00.

## The WELCOME10 experiment

- Each new customer is randomly assigned to **control** (50%) or **treatment** (50%).
- Treatment customers are offered WELCOME10 for their first order.
- An eligible treatment customer (subtotal ≥ $50) uses the code 85% of the time.

**Built-in effect (disclosed):** before their first order, treatment
customers are 15% more likely to complete a checkout they started. Any
difference found between the groups comes from this assumption plus random
noise. The analysis question is whether the data shows it clearly and how
big it looks, not whether discounts work in real life.

## Known simplifications

- Every session belongs to a known customer; there are no anonymous visitors.
- Each customer's first visit is their signup day.
- No returns, refunds or cancellations.
- Inventory is not reduced by purchases, and prices don't change over time.
- Conversion is higher than a typical real store (about 11% of sessions end
  in an order, vs roughly 2–5% in real e-commerce), because every visitor
  here is a registered customer.
